# PrimeNest Real Estate

A responsive multi-page real estate website built with HTML5, CSS3 and vanilla JavaScript.

## Pages

- Home (`index.html`)
- Properties with live search, filters and sorting
- Property details with gallery, map and agent contact panel
- Agents, About and Contact pages

## Run locally

Open `index.html` in a browser, or serve the folder with any static-file server. The site is deployment-ready for GitHub Pages, Netlify, or Vercel.

Images, fonts, icons, and map embeds are loaded from public CDNs, so an internet connection is needed to view them.
